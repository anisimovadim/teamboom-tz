# Верхняя часть карточки товара Teaboom.ru

Тестовое задание: «Ананасовый улун». Реализован компактный блок с фотографией,
названием, категорией, выбором фасовки, артикулом, ценами, кнопкой «В корзину»
и коротким описанием. Оформление сохраняет стилистику исходника: Open Sans,
фон с узором, кремовые и серые поверхности, тёмный текст и жёлтый акцент.

## Запуск

1. Откройте страницу репозитория на GitHub.
2. Нажмите зелёную кнопку **Code** и выберите **Download ZIP**.
3. Распакуйте скачанный архив и откройте папку проекта.
4. Найдите файл `index.html` и откройте его в браузере.

Изображения и шрифты локальные. Сервер, сборка, установка зависимостей и
интернет для работы карточки не нужны.

## Структура

```text
index.html        — HTML5-разметка карточки
css/styles.css    — оформление, Grid / Flexbox, адаптивность
js/product.js     — выбор фасовки и демонстрация добавления
assets/images/    — фотография и фон
assets/fonts/     — Open Sans, значок корзины Themify и лицензии
README.md         — запуск, требования и источники
```

## Функциональность

- Четыре фасовки с обновлением выбранного состояния, артикула и обеих цен. По умолчанию — 100 г.
- Общая кнопка «В корзину» вместо отдельных кнопок для каждой фасовки: меньше повторяющихся элементов и понятнее порядок покупки.
- Уведомление о добавлении оформлено в стиле карточки: кремовый фон, тёмный текст и жёлтый акцент. Закрывается крестиком, Escape или при смене фасовки.
- Поддерживаются мышь, касание и клавиатура. Вёрстка адаптирована для 1440, 768 и 375 px.

Корзина и оформление заказа работают в демонстрационном режиме, без backend и API.

## Проверка требований

- Все элементы верхней карточки включены.
- Выбор фасовки виден с загрузки; цены и артикул обновляются на странице.
- У кнопки «В корзину» есть состояния наведения и клавиатурного фокуса.
- Вёрстка адаптирована для 1440, 768 и 375 px.
- Используются HTML5, CSS и небольшой JavaScript без фреймворков и Bootstrap.
